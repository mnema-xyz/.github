# .github

Organization-wide files for [Mnema](https://github.com/mnema-xyz):

- [`profile/README.md`](profile/README.md): the organization's profile page.
- [`SECURITY.md`](SECURITY.md): the default security policy for repositories without their own.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), the issue forms and the pull request template in
  [`.github/`](.github/): defaults for repositories that do not define their own.
